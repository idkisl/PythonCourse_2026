ДОМАШНЕЕ ЗАДАНИЕ VK bot

ОБЩИЕ УКАЗАНИЯ

1. Используйте Python и библиотеку vk_api: pip install vk_api.
2. Работайте с тестовым сообществом ВКонтакте. Включите сообщения сообщества,
   Bots Long Poll API и тип события message_new.
3. Ключ доступа и GROUP_ID храните отдельно от основного кода, например в
   PERSONAL_DATA.py (файл с токеном нельзя публиковать или сдавать в открытом виде).
4. Для получения событий используйте VkBotLongPoll и VkBotEventType.MESSAGE_NEW.
   Для отправки сообщений используйте vk.messages.send с peer_id и random_id.
5. Исключите обработку собственных исходящих сообщений. Учитывайте, что
   from_id — отправитель, а peer_id — диалог, в который надо отвечать.
6. Состояния разных пользователей/диалогов не должны смешиваться.
7. Команды «Начать», «Помощь», «Отмена» (там, где предусмотрены) должны работать
   предсказуемо. Нажатие «Выход» не должно завершать весь процесс через sys.exit().
8. Каждый бот запускается отдельно и проверяется реальной перепиской с сообществом.
   Код пишите самостоятельно; готовые решения не требуются.



ЗАДАНИЕ 1. ЭХО-БОТ
Файл: echo-bot.py

Создайте бота, который повторяет текст каждого полученного сообщения.
Требования:
- Получить text и peer_id из события MESSAGE_NEW.
- Отправить пользователю текст «Эхо: <полученное сообщение>».
- Вывести в консоль peer_id и текст входящего сообщения.
- Не отвечать на собственные исходящие сообщения.

Проверка: отправьте обычное сообщение, сообщение с цифрами и пустой текст
(например, вложение без подписи). Для пустого текста выведите понятный ответ.

ЗАДАНИЕ 2. БОТ-ПРИВЕТСТВИЕ
Файл: hello-bot.py

Создайте бота, отвечающего на команды:
- «привет» — приветствие;
- «пока» — прощание;
- «помощь» — список доступных команд;
- любая другая команда — сообщение о неизвестной команде.

Требования:
- Вынести выбор ответа в функцию get_answer(text).
- Использовать lower() и strip() для нормализации текста.
- Создать обычную клавиатуру VkKeyboard(one_time=False) с кнопками
  «Привет», «Пока» и «Помощь»; разнести кнопки на две строки.
- Использовать хотя бы два значения VkKeyboardColor.

Проверка: «ПрИвЕт», « привет » и нажатие кнопки «Привет» дают один ответ.



ЗАДАНИЕ 3. МАТЕМАТИЧЕСКИЙ БОТ
Файл: easy-math-bot.py

Создайте бота для решения уравнения a*x^2 + b*x + c = 0.
Пользователь должен иметь возможность запускать решение командой «Уравнение».

Требования:
- Реализовать команды «Начать» и «Помощь».
- Последовательно запросить a, b, c отдельными сообщениями.
- Использовать словарь состояний: ожидание a, ожидание b, ожидание c.
- Сохранять уже введённые коэффициенты до завершения решения.
- Проверять ввод чисел; при ошибке повторить запрос, не теряя прогресс.
- При a = 0 корректно решить получившееся линейное/вырожденное уравнение.
- При a != 0 рассмотреть D > 0, D = 0 и D < 0. Договоритесь, что
  рассматриваются действительные корни: при D < 0 сообщить об их отсутствии.
- Добавить команду «Отмена», возвращающую в главное меню.

Проверка: (1, -3, 2), (1, 2, 1), (1, 0, 1), (0, 2, -4), (0, 0, 0),
а также неверный ввод коэффициента.



ЗАДАНИЕ 4. БОТ-КОНВЕРТЕР ВАЛЮТ
Файл: currency-converter-bot.py

Создайте бота, переводящего сумму из одной валюты в другую.
Последовательность диалога:
  1) выбор исходной валюты;
  2) выбор целевой валюты;
  3) ввод суммы;
  4) показ результата и курса обмена.

Требования:
- Поддержать не менее трёх валют (например, RUB, USD, EUR).
- Выбор валюты реализовать через inline-клавиатуру
  VkKeyboard(inline=True) с текстовыми кнопками add_button(..., payload=...).
- Для определения выбранной валюты извлекать payload из MESSAGE_NEW
  и преобразовывать его с помощью json.loads().
- Хранить этап диалога, исходную и целевую валюты отдельно для каждого диалога.
- Получать актуальный курс из публичного валютного API, изученного ранее,
  либо другого доступного официально документированного источника.
  Указать в коде/README источник и дату-время полученного курса.
- Проверять положительность суммы и корректность ответа внешнего API.
- Добавить команды «Начать», «Помощь» и «Отмена».
- Не выдавать выдуманный курс, если внешний сервис недоступен.

Проверка: разные пары валют, одинаковая исходная и целевая валюты,
некорректная сумма и временная недоступность API.



ЗАДАНИЕ 5 (ДОПОЛНИТЕЛЬНОЕ ЗАДАНИЕ). УЧЕБНЫЙ ЭЛЕКТРОННЫЙ ЖУРНАЛ
Файл: electronic-diary-bot.py

Создайте учебную имитацию электронного журнала для преподавателей и учеников.
В словаре или JSON-файле хранится информация о преподавателях,
учениках, предметах и оценках.

Требования:
- Команда «Начать» предлагает выбрать роль кнопкой: «Преподаватель» или «Ученик».
- Преподаватель вводит отображаемое имя и регистрируется в системе.
- Ученик выбирает преподавателя из списка зарегистрированных преподавателей.
- Для упрощения один ученик прикреплён к одному преподавателю
  и изучает у него один предмет.
- Преподаватель может выбрать своего ученика и выставить оценку от 2 до 5.
- Ученик видит список своих оценок и средний балл (если оценки есть).
- Создать обычное главное меню и inline-кнопки для выбора роли,
  преподавателя или ученика; для действий использовать payload.
- Реализовать последовательные состояния регистрации и выставления оценки.
- Хранить данные разных диалогов раздельно, предусмотреть «Назад» и «Отмена».
- Сохранять данные в JSON, чтобы оценки не исчезали после перезапуска.

ВАЖНО ПО БЕЗОПАСНОСТИ: один лишь выбор роли «Преподаватель» не доказывает,
что пользователь действительно преподаватель. Для учебного макета используйте
тестовые вымышленные данные. Доступ к выставлению оценок разрешайте только
VK user_id, заранее внесённым в список разрешённых преподавателей.
Не используйте настоящий школьный журнал и реальные персональные данные.

Проверка: два разных ученика, два преподавателя, попытка ученика выставить
оценку, перезапуск бота и восстановление сохранённых оценок.
