Учебный проект: ORM и SQLAlchemy

1. Откройте папку проекта в PyCharm или другой IDE.
2. Установите библиотеку: pip install -r requirements.txt
3. Если в SQLiteStudio уже создана studio_people.db, скопируйте её
   в корень проекта. Иначе база и таблицы будут созданы при запуске.
4. Запустите main.py из корня проекта.
5. Откройте studio_people.db в SQLiteStudio и изучите записи.

Каждый запуск main.py добавляет одного нового студента с оценкой.
Примеры удаления закомментированы, чтобы не удалять данные автоматически.
